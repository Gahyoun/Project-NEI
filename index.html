고정된 topology-to-geometry protocol

네트워크의 geometric representability와
embedding identifiability

두 명사는 서로 다른 질문이고, 결정적으로 protocol 의존성이 서로 다르다. representability 는 graph metric 하나에서 eigendecomposition 한 번으로 나오는 닫힌 형태이고, identifiability 는 비퇴화 확률 protocol 아래에서만 정의되는 sampling estimator 이다.

핵심 결과 — NEI 는 energy landscape 의 real degeneracy 를 잰다

sklearn 의 stopping rule 은 상대 stress 개선량을 기준으로 삼으며, 그 지점의 무차원 stationarity 지표 $\eta_g$ 는 L-BFGS 가 도달하는 값보다 5 자릿수 크다. 각 terminal 을 L-BFGS 로 polish 해 stationary point 까지 밀어넣고 거기서 다시 측정한다.

결론. polish 된 terminal 은 전부 진짜 local minimizer 이고(음의 eigenvalue 0개), 24개 run 이 서로 다른 24개 minimizer 로 가며, $K$ 는 cutoff 를 6 자릿수 움직여도 변하지 않는다. 인증된 minimizer 위에서 재도 $\mathcal{I}$ 는 같은 크기로 남는다. NEI 는 stress landscape 의 real degeneracy 를 잰다. network 4개에서 $\mathcal{I}$ 는 optimizer 에 거의 의존하지 않는다 — 수렴 품질이 6 자릿수 다른데 값은 15% 안에서 같다.

이 진술의 범위는 검사한 network 이다. 전 표본으로 확장하려면 polish 를 전면 적용한다.

    지도의 모든 간선은 아래 다섯 장치 중 하나를 지난다. 개념이 많아 보여도 연결을 지탱하는 수학적 장치는 다섯 개뿐이다.

    Representability — protocol 이 개입하지 않는 축

    $\mathcal{D}_p=0$ 은 graph metric 이 $\mathbb{R}^p$ 에서 정확히 실현되는 것과 동치이다(Schoenberg). eigendecomposition 한 번으로 닫힌 형태로 결정되며, graph metric 하나에만 의존한다.

    random geometric graph 에서 Euclidean 구조를 갖는 것은 잠재 좌표이다. 같은 점집합의 좌표 거리는 $\mathcal{D}_2=0.000$ 인 반면, hop metric 은 $\mathcal{D}_2=0.464$ 로 격자($0.406$)를 웃돌고 밀도를 올리면 $0.648$ 까지 커진다 — hop 이 포화하기 때문이다.

    벡터로 energy landscape 를 분해한다

    $\mathcal{I}$ 는 terminal covariance operator 의 trace 이고, 그 spectrum 이 같은 연산자의 모양을 담는다. trace 는 degeneracy 의 크기를, participation ratio $d_{\mathrm{eff}}$ 는 degeneracy 가 차지하는 자유도의 수를 준다. 두 축이 함께 다중안정형과 floppy 를 가른다. spectrum 은 이미 저장된 $\Delta$ 에서 복원되므로 재실행이 필요 없다.

    1차원 stress landscape 에서 같은 분해를 본다. 초기조건을 균등하게 뿌리고 $T=0$ 하강을 돌린 terminal 분포이며, 분산과 participation ratio 를 함께 읽는다.
