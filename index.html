Graph metric의 geometric representability와
embedding protocol의 terminal multiplicity

측정 대상부터 고정. Population protocol $\Pi$는 $G\mapsto\Delta$, target dimension $p$, pair weights, optimizer, stopping rule, initialization law $\rho_0$와 algorithmic randomness $\rho_{\rm alg}$를 모두 포함. $\mathcal D_p$는 fixed $(\Delta,p)$에서의 spectral representability diagnostic이고, $\mathcal I$는 $\Pi$가 유도하는 terminal-geometry law의 response observable. 같은 network에 대한 서로 다른 질문. 반복수 $M$은 population estimand가 아니라 empirical estimator의 sample size, Monte Carlo precision과 rare-class detection power를 결정. geometric resolution은 별도로 선언한 $\varepsilon_D$로 결정.

Definition — realized geometric degeneracy

Realized geometric degeneracy는 fully specified protocol 아래의 admissible terminal law가, 사전에 선언한 dimensionless pair-distance metric $\rho_D$와 resolution $\varepsilon_D$에서 한 점으로 수축하지 않는 성질. 따라서 prespecified positive-weight pair set $\mathcal P$, $S_{\Delta,W}>0$ 및 $\alpha_\Pi>0$ 아래 population-level definition: $\operatorname{diam}_{\rho_D}\operatorname{supp}(\mu_\Pi^{\rm adm})>\varepsilon_D$. $N_+=|\mathcal P|$로 설정. 모든 prespecified pair $a\in\mathcal P$에 대해 $0<\mathbb E[d_a]<\infty$와 $\mathbb E[d_a^2]<\infty$를 가정. $\rho_\mu^2(d,d')=N_+^{-1}\sum_{a\in\mathcal P} [(d_a-d'_a)/\mathbb E(d_a)]^2$로 정의할 때, iid $D,D'\sim\mu_\Pi^{\rm adm}$에 대해 $\mathcal I=\tfrac12\mathbb E[\rho_\mu^2(D,D')]$. 따라서 $\mathcal I=0$ iff $\mu_\Pi^{\rm adm}$ is a point mass. NEI의 exact zero-set statement. 그러나 $\rho_\mu$와 $\rho_D$는 positive threshold에서 일반적으로 동치가 아니므로, $\mathcal I>0$만으로 $\rho_D$-diameter가 $\varepsilon_D$를 넘는다는 결론은 불가. NEI의 크기는 이 distribution의 geometry-weighted second moment를 측정. state count, equal-energy degeneracy, barrier 또는 continuous minimizer manifold는 이 scalar 하나로 식별 불가.

여기서 $\mu_\Pi^{\rm adm}=\mathcal L(q(T_\Pi)\mid A_{\rm num})$이고 $\alpha_\Pi=\Pr(A_{\rm num})$를 함께 보고. $A_{\rm num}$은 optimizer success, stationarity, collision과 quotient-Hessian inertia를 검사. 별도의 representational-fidelity criterion은 topology-to-geometry interpretation이 유효한 범위를 설정. numerical admissibility와 representational fidelity는 서로 다른 질문이며 상호 대체 불가.

현재 evidence가 허용하는 결론. legacy runs에서 $\eta_g$가 $2.19\times10^{-3}$에서 $2.00\times10^{-8}$로 감소하는 동안 $\widehat{\mathcal I}_M$는 $0.1100$에서 $0.07665$로 감소했고, 24개 terminal distance matrices는 보고된 cutoff 범위에서 분리. 이 결과가 직접 허용하는 conclusion은 stated polishing schedule이 observed terminal-distance dispersion을 제거하지 못했다는 사실. corrected implementation 이전의 all-run ungated diagnostic이므로, corrected numerical gate와 independent-batch recurrence 전에는 recurrent terminal multiplicity나 multiple local minima에 대한 결론 유보.

Terminology. “Realized”는 declared protocol이 실제로 점유하는 terminal geometry를 지칭. finite-$M$ 표본이 population support를 이미 certified했다는 의미는 아님. gate acceptance rate, independent-batch recurrence와 finite-$M$ stability의 병행 보고 필요. complete-support detection에는 minimum-mass 또는 missing-mass assumption이 추가로 필요. equal stress, continuous minimizer manifold와 optimizer-independent global nonuniqueness에는 각각 별도 certificate 요구.

    Connectors — equivalence, implication, and analogy

    각 edge에 관계의 이름과 epistemic status를 부여. equivalence는 양방향 명제, implication은 명시된 가정 아래의 단방향 명제, analogy는 해석을 돕는 대응이며 proof는 아님. graph의 연결 자체를 mechanism이나 causality로 해석하지 않음.

    Representability — fixed $(\Delta,p)$의 spectral diagnostic

    finite, symmetric, hollow, nonnegative dissimilarity $\Delta$를 고정. 이때 $\mathcal D_p=0$은 $\Delta$가 $\mathbb R^p$에서 exact Euclidean realization을 갖는 것과 동치. $B=0$에는 $\mathcal D_p=0$ convention을 적용. 이 zero set은 theorem이지만 positive magnitude는 chosen normalization에 따른 diagnostic. $\mathcal D_p$는 optimizer-independent이며 $G\mapsto\Delta$와 $p$에는 의존. 해석할 때는 positive-spectrum rank truncation인 $\mathcal D_p^{\rm dim}$과 negative-spectrum obstruction인 $\mathcal D^{\rm neg}$를 우선 분리.

    Baseline before interpretation. random geometric graph의 Euclidean object는 latent coordinate metric이며 hop metric은 아님. 같은 point cloud에서 coordinate distance는 $\mathcal{D}_2=0.000$이지만 hop metric은 $\mathcal{D}_2=0.464$이고, 이 한 표본에서는 lattice($0.406$)보다 큰 값. density 증가에 따라 $0.648$까지 증가. 이 ordering은 descriptive result. hop-shell compression을 mechanism으로 주장하려면 $N$, density, connectedness와 degree heterogeneity를 matched한 graph ensemble 및 rewiring null이 선행 필요.

    한 scalar의 trace, spectrum, occupancy decomposition

    pair-standardized vector $z_{ma}=d_a^{(m)}/(\bar d_a\sqrt{N_+})$에 대해서만 finite-sample plug-in identity $\widehat{\mathcal I}_M=\operatorname{tr}B_z/M$이 exact. population NEI의 unbiasedness statement는 아님. 같은 operator의 spectrum에서 얻는 participation ratio는 covariance effective rank이며, class occupancy에서 얻는 $K_{\rm eff}$와는 다른 observable. 전자는 terminal cloud가 퍼지는 독립 방향의 유효 수를, 후자는 observed class probability가 나뉘는 유효 수를 요약. 기존 global-scale run-distance matrix $\Delta^{(\rm raw)}$는 raw-cloud spectrum만 복원하므로 standardized artifact $\Delta^{(z)}$의 재저장 필요. 어떤 $\bar d_a=0$이면 NEI는 undefined이며 해당 pair를 post hoc으로 제거해 estimand를 바꾸지 않음.

    Claim ledger

    각 문장을 definition, theorem, diagnostic, exploratory measurement, open certificate 또는 withdrawn claim으로 분류. 숫자의 존재만으로 diagnostic을 conclusion으로 승격하지 않음. 각 row의 basis에는 해당 claim을 허용하는 assumption·calculation·baseline을 명시.
