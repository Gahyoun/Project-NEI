고정된 topology-to-geometry protocol

네트워크의 geometric representability와
embedding identifiability

두 명사는 서로 다른 질문이고, 결정적으로 protocol 의존성이 서로 다르다. representability 는 graph metric 하나에서 eigendecomposition 한 번으로 나오는 닫힌 형태이고, identifiability 는 비퇴화 확률 protocol 아래에서만 정의되는 sampling estimator 이다.

핵심 결과 — NEI 는 SMACOF 의 인공물이 아니다

SMACOF terminal 은 stationary point 가 아니다. sklearn 의 stopping rule 은 상대 stress 개선량이지 optimality gap 이 아니어서, 실측 $\eta_g$ 가 L-BFGS 보다 5 자릿수 크다. 그래서 각 terminal 을 L-BFGS 로 polish 해 진짜 stationary point 까지 밀어넣고 다시 측정했다.

결론. polish 된 terminal 은 전부 진짜 local minimizer 이고(음의 eigenvalue 0개), 24개 run 이 서로 다른 24개 minimizer 로 가며, $K$ 는 cutoff 를 6 자릿수 움직여도 변하지 않는다. 인증된 minimizer 위에서 재도 $\mathcal{I}$ 는 같은 크기로 남는다. NEI 가 재는 것은 stress landscape 의 실제 degeneracy 이다.

단, 이는 검사한 network 에 대한 진술이다. 전 표본으로 확장하려면 polish 를 전면 적용해야 한다.

연결요소 — 무엇이 이 개념들을 같은 대상으로 만드는가

지도의 모든 간선은 아래 다섯 장치 중 하나를 지난다. 개념이 많아 보여도 연결을 지탱하는 수학적 장치는 다섯 개뿐이다.

Representability — protocol 이 개입하지 않는 축

$\mathcal{D}_p=0$ 은 graph metric 이 $\mathbb{R}^p$ 에서 정확히 실현되는 것과 동치이다(Schoenberg). 임베딩을 돌리지 않으므로 sampling 문제가 없다.

random geometric graph 에서 Euclidean 인 것은 잠재 좌표이지 graph metric 이 아니다. hop metric 의 $\mathcal{D}_2$ 는 $0.464$ 로 격자($0.406$)보다 크고, 밀도를 올리면 $0.648$ 로 더 나빠진다. 같은 점집합의 좌표 거리는 $\mathcal{D}_2=0.000$ 이다.

스칼라 하나로는 부족하다

$\mathcal{I}$ 는 terminal covariance operator 의 trace 이다. trace 는 크기만 말하고 모양을 말하지 않으므로, 다중안정형과 floppy 를 원리적으로 구분하지 못한다.

1차원 stress landscape 로 본 같은 이야기. 초기조건을 균등하게 뿌리고 $T=0$ 하강을 돌린 terminal 분포이다.
